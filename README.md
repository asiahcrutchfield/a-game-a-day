# A Game a Day

My journey to learn game development by making small games that can be finished within 24–72 hours, give or take.

I'm starting with [PICO-8](https://www.lexaloffle.com/pico-8.php), focusing on completing small games regularly so I can learn by actually making things. Since I'm also currently a student, "a game a day" isn't a strict schedule—it's more of a goal to keep creating, experimenting, and improving whenever I have the time.

This repository is a record of that journey.
